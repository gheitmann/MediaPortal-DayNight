# Changelog

## v0.2.0-alpha.1 — 2026-10-26

First standalone public preview, extracted from the Backdrop prototype.

- Four configurable phases and six modes, including permanent Morning and Noon.
- Native in-skin configuration with staged Save/Cancel behavior.
- Independent external configuration and 37 UI language catalogues.
- Version-1 preference migration preserving existing bright-interval endpoints.
- Capability detection and fallback for unsupported or two-period skins.
- AnyCPU build with x86/x64 assembly probes and an x64 full-client smoke check.
